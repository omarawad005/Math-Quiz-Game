\## 📌 About The Project



\*\*Math Quiz Game\*\* is a console-based game developed using \*\*C++\*\*.



The game generates random mathematical questions based on the selected difficulty level and operation type. The player answers each question, and the game checks the answer and keeps track of the correct and incorrect responses.



At the end of the game, the final result is displayed with the selected level, operation type, and overall performance.

\## 🎮 How The Game Works



The game starts by asking the player to enter the number of questions.



Then the player selects:



1\. The number of questions

2\. The operation type

3\. The difficulty level



For every question:



```text

Generate Random Numbers

&#x20;         ↓

&#x20;  Select Operation

&#x20;         ↓

&#x20;   Display Question

&#x20;         ↓

&#x20;   Player Enters Answer

&#x20;         ↓

&#x20;    Check The Answer

&#x20;         ↓

&#x20;  Update Score \& Result

```



After all questions are completed, the game displays the final results.

\## 🏆 Final Results



After completing all questions, the game displays:



```text

=================================

Number of Questions  : 5

Level of Game        : Easy

Operation Type       : Add

Correct Answers      : 4

Incorrect Answers    : 1

=================================

```



The final result can be:



\* 🏆 \*\*Pass\*\* — Correct answers are greater than incorrect answers.

\* ❌ \*\*Fail\*\* — Incorrect answers are greater than correct answers.

\* 🤝 \*\*Draw\*\* — Correct and incorrect answers are equal.
